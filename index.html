INSTALL ON IPHONE

加入 iPhone 主畫面

  1. 請先用 Safari 開啟 GitHub Pages 網址。
  2. 按 Safari 下方或上方的「分享」圖示。
  3. 往下選擇「加入主畫面」。
  4. 按「新增」，之後就能像 App 一樣開啟。

安裝後可快速開啟，已載入過的網站頁面也能離線使用；第一次 OCR 仍需要網路下載辨識模型。
